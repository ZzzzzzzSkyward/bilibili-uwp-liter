# 帮助

这是哔哩哔哩的第三方 UWP 客户端。本页说明常见问题、设置项作用、快捷键和反馈方式，内容随安装包提供。外部链接只作补充资料，内容可能与当前版本不一致。

## 常见问题

### 视频或直播无法播放

- 到 设置 → 播放 → 播放兼容性 → 视频格式 换一种封装或编码，再到 首选播放器 换一个播放引擎。
- 需要购买或大会员的内容，先在网页或手机客户端开通，然后回到应用重试。
- 视频编码为 HEVC 时，系统需要安装 [HEVC 扩展](ms-windows-store://pdp/?productid=9n4wgh0z6vhq)。
- 视频编码为 AV1 时，系统需要安装 [AV1 扩展](ms-windows-store://pdp/?productid=9MVZQVXJBQ9V)，部分清晰度可能也需要 HEVC 扩展。
- 更新显卡驱动，或改用集成显卡启动应用。
- 直播还受网络和地区解析影响：可试 设置 → 网络与解析 → 视频 CDN 里的 CDN 替换、CDN 节点。

### 没有声音或画面异常

- 播放器内用 ↑ / ↓ 调整音量，F3 / V 切换静音；同时检查系统音量和输出设备。
- 绿屏、黑屏或卡顿：回到 设置 → 播放 → 播放兼容性，换 视频格式 或 首选播放器；仍然异常可更新显卡驱动。
- 掉帧可能与显卡垂直同步有关，可参考外部文章排查。

### 字幕

- 设置 → 播放 → 字幕：默认开启 AI 字幕 会在有 AI 字幕时默认选用，可能与画面内字幕重叠；繁体字幕转简体 同时影响播放器和下载的字幕。
- 播放器侧边栏的 字幕 页可调节字幕大小、颜色、加粗和多行对齐，也可用 导入字幕 载入本地字幕文件。
- 本地轨道 页的 字幕轨道 → 选择字幕 可在多轨视频里切换字幕。

### 弹幕

- 播放器侧边栏的 弹幕 页会显示 弹幕数量。数量不为 0 但仍看不到时，检查 设置 → 视频弹幕 → 屏蔽规则 里的关键词屏蔽、用户屏蔽、正则屏蔽。
- 弹幕数量为 0 时，点 更新弹幕 重新获取，也可用 导入弹幕 载入本地弹幕文件。
- 是否默认显示弹幕由 设置 → 视频弹幕 → 显示 → 默认显示弹幕 决定；直播弹幕在 直播弹幕 页单独设置。
- 用户屏蔽按弹幕发送者的标识匹配，不是账号 UID。

### 部分图片无法显示

- 安装 [WebP 图片扩展](ms-windows-store://pdp/?productid=9PG2DK419DRG) 后可以显示 WebP 图片。
- 设置 → 外观与浏览 → 图片 → 加载原图 开启后会加载原始尺寸的图片，可能增加下载量和内存占用。

### 下载视频失败

- 检查磁盘剩余空间。
- 使用按流量计费的网络时，需要在 设置 → 下载 → 下载行为 → 允许按流量计费网络 打开。
- 设置 → 下载 → 存放位置 → 下载目录 可打开或更改目录；更改目录不会迁移已有文件。
- 任务长时间没有进度时，删除任务和已下载文件后重新下载。
- 旧版下载：打开 设置 → 下载 → 旧版下载 → 加载旧版下载，并在 旧版下载目录 指定旧版读取位置；旧版目录与新的下载目录分开。

### 无法联网

- 多半是系统代理引起：关闭系统代理后重试。
- 使用代理软件时，确认代理对应用生效，否则应用可能仍然直连失败。

### 中文乱码

- 打开系统设置 → 时间和语言 → 语言 → 管理语言设置 → 更改系统区域设置，把“非 Unicode 程序的语言”设为中文，重启系统后生效。

### 搜索时自动跳转页面

- 搜索 av10086、ss36297 这类关键词时会自动匹配并跳到对应页面。
- 在关键词前加 @ 就不会跳转，例如 @av10086。

## 设置说明

### 外观与浏览

- 外观：主题、背景图片、动态页背景、图片圆角。
- 首页：首页导航 可拖动排序，右键或长按移除；另有 推荐布局、动态布局、隐藏推荐横幅、缓存首页。
- 视频详情：详情栏宽度、显示视频封面、默认详情页签。
- 图片：加载原图、图片预览新开窗口，以及 清除图片缓存 按钮。
- 页面操作：窗口模式、鼠标返回、用浏览器打开未知链接。
- 窗口模式 有 标签页、单窗口、多窗口 三种，更改后需要重启应用生效。
- 首页缓存与图片缓存不是一回事：缓存首页 保存的是首页各页的页面状态，返回时减少重新加载；清除图片缓存 清掉的是图片缓存文件，不会删除已下载的视频和首页配置。

### 播放

- 播放行为：自动开播、自动连播（按播放目录和来源继续）、记忆播放进度、默认倍速。
- 显示方式：自动全屏、自动铺满窗口、双击动作。
- 自动全屏优先：开启自动全屏时，初始显示方式由全屏决定，自动铺满窗口不参与决定；只开自动铺满窗口时，播放器在应用窗口内展开。
- 双击动作：开启后双击切换全屏，关闭后双击播放或暂停。
- 字幕：默认开启 AI 字幕、繁体字幕转简体。
- 播放兼容性：视频格式 同时选择封装与编码（FLV / H.264、DASH / H.264、DASH / HEVC、DASH / AV1）；首选播放器 可选 自动选择、系统播放器优先、FFmpeg 软解、FFmpeg 自动解码，首选不保证每个视频都只用这一引擎。
- 视频无法播放时，视频格式 和 首选播放器 都值得各换一次。

### 视频弹幕

- 显示：默认显示弹幕、顶部留白（直播页也读取此值）、每秒上限（0 表示不限）。
- 屏蔽规则：关键词屏蔽、用户屏蔽、正则屏蔽。
- 规则文件：从账号导入 读取 B 站账号的屏蔽规则并合并到本地；导入规则 和 导出规则 使用 JSON 文件，导入只合并不覆盖现有列表。

### 直播弹幕

- 默认显示弹幕、关键词屏蔽；直播关键词与视频弹幕关键词分别保存。

### 下载

- 存放位置：下载目录。
- 下载行为：视频格式、并行下载、允许按流量计费网络、下载完成通知。
- 视频格式 可选 FLV / H.264、M4S / H.264、M4S / HEVC、M4S / AV1；选择 FLV 时不支持 4K 下载，部分视频不支持 M4S。
- 旧版下载：加载旧版下载、旧版下载目录。

### 账号

- 登录：登录状态，以及 刷新登录、重新登录、退出登录。
- 手动填写会话信息：展开后可填 access_key、SESSDATA、bili_jct、ac_time_value，取法见下方“账号帮助”。

### 网络与解析

- 视频 CDN：CDN 替换 可选 不替换、替换全部视频、仅替换 PCDN 视频、仅替换代理视频；CDN 节点 配合 测试延迟 使用，显示的是本次请求耗时或超时，不代表实际播放速度。
- 地区解析：默认解析服务器、香港服务器、台湾服务器、大陆服务器；回车或点输入框右侧按钮保存，香港、台湾、大陆留空则使用默认服务器；部分公共解析服务器需要登录才能使用。

### 诊断

- 反馈工具：标记问题、导出诊断包、导出日志、打开日志目录。
- 日志持续写入文件：先用 标记问题 记下问题发生的时间点（可填一句描述），复现后 导出诊断包 打包近期日志、已采集的 API 记录和清单；只需要运行日志时用 导出日志。
- API 采集：记录 API 响应结构 会把响应字段和结构变化写入 LocalState\log\api，第一份结构作为基线，之后的字段变化记为一次漂移；记录正文样本 额外保留脱敏后的短正文样本，每份最多 4 KB，需要先开启 记录 API 响应结构。
- 日志内容可能包含请求参数，分享前请检查。

### 帮助与关于

- 帮助 页显示本文件；关于 页显示当前安装包的版本和项目说明。

| --- | --- |

### 播放器

| 按键 | 作用 |
| --- | --- |
空格 | 播放 / 暂停
← / → | 后退 / 前进 3 秒；按住 Ctrl 为 0.5 秒，按住 Shift 为 30 秒
↑ / ↓ | 音量增加 / 减少 10%
Esc | 退出全屏
Enter / F / F11 / F12 / W | 切换全屏
F8 / T | 小窗播放
F9 / D | 打开 / 关闭弹幕
F10 | 截图
O / P | 跳过 OP，前进 90 秒
Z / N / < | 上一分 P
X / M / > | 下一分 P
F1 / ; | 减慢播放速度

## 账号帮助

### 常规登录

- 设置 → 账号 → 登录 → 登录状态 显示当前登录状态。
- 点 重新登录 走正常登录流程；登录状态异常时先点 刷新登录；更换账号时用 退出登录。

### 手动填写会话信息

常规登录不可用时，在 设置 → 账号 → 登录 → 手动填写会话信息 里填写。

1. 用浏览器登录 bilibili.com。
2. 打开浏览器的开发者工具，在网站的 Cookie 或站点数据里找到 `bilibili.com`，复制 SESSDATA、bili_jct、ac_time_value 的值。
3. access_key 是应用登录后得到的令牌，应用里点 显示 可查看当前值，一般不需要手动填写。
4. 填入后立即保存；留空的字段不会改动已存的值，只有 ac_time_value 留空会删掉它。

这些值等同于账号凭据，不要分享给他人。

## 问题反馈

1. 记下复现步骤和发生时间。
2. 复现问题后，打开 设置 → 诊断 → 反馈工具，点 标记问题，把时间点和简要描述写进日志。
3. 点 导出诊断包 导出近期日志、已采集的 API 记录和清单；只需要运行日志时用 导出日志。
4. 也可以点 打开日志目录 自行查看。

- 日志目录：`%USERPROFILE%\AppData\Local\Packages\BilibiliUWPLiter_agd62dfed6f7t\LocalState\log`
- [打开日志目录](OpenLog)
- 发送日志前请删除 access_key、SESSDATA 等内容。

## 默认保存位置

| 内容 | 默认位置 |
| --- | --- |
截图 | `%USERPROFILE%\Pictures\哔哩哔哩截图`
下载 | `%USERPROFILE%\Videos\哔哩哔哩下载`

- `%USERPROFILE%` 是当前用户目录，例如 `C:\Users\用户名`。
- 下载目录可在 设置 → 下载 → 存放位置 → 下载目录 更改。

## 1. 未完成项

### 1.1 [ ] 后台播放归属（P1，阻塞：需要设备测量）

- 来源：[plan/PLAN.md](../plan/PLAN.md) 第 2 项、[bug_report.md](../bug_report.md) BR-21。
- 现状：`backgroundMediaPlayback` 已在两个清单里声明，播放器的播放/暂停与状态也接了；缺的是**归属**——
  系统媒体控制是视图级的，`OnUnload` 会给每个控件都关一次，于是离开标签页会把仍在播放的那个播放器
  的控制关掉。`App.OnSuspending` 目前不做播放器工作，却在挂起窗口里强制等待终结器。
- 验收：一个活动播放所有者跨标签页与可见性变化保持 SMTC 会话；切到后台时释放可选的视觉/弹幕工作；
  挂起窗口内的等待有界；回到前台不重建播放器。
- 下一步：先按 BR-21 的要求拿到分层测量（仅滚动动态 / 仅播放 / 开弹幕 三种行程的 N 分钟后工作集，
  以及托管堆 vs 原生），再决定是否值得重构。

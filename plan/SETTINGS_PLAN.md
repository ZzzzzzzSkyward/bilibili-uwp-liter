## 2. 播放

常用行为放在前面，编码和引擎放在末尾的“播放兼容性”组。CDN 移到“网络与解析”；原“代理”页的字幕转换移入这里。

| 顺序 | 建议名称 | 原控件 | 说明、选项或操作 |

| 2.3 | 双击动作 | `swPlayerSettingDoubleClickFullScreen` | 全屏、播放或暂停。建议改为两项选择控件；沿用原布尔值映射：开为全屏，关为播放或暂停 |

“自动全屏”和“自动铺满窗口”不能简单合并或删掉：当前消费者分别读取它们，且先判断全屏。第一轮整理保留原值、原优先级，并把优先关系写进帮助文本。

## 随整理应处理的行为问题

这些问题会影响设置是否可信，优先于间距和卡片样式。它们属于当前源码问题，本报告没有宣称已经修复。

### 先修：打开设置会破坏自定义 API 路径

位置：[SettingPage.xaml.cs:707](src/BiliLite.UWP/Pages/SettingPage.xaml.cs#L707)。`api_web_secondary` 从 `api_web_top` 读取，而不是从自己的键读取。构造函数随即执行 `LoadAPI → InitApi → SaveSettings`，所以只要打开设置，就可能把原来的路径前缀覆盖成基础地址；不需要点击“修改”。

修法：读取正确的 `api_web_secondary`；加载控件和应用配置不要顺带回写存储，只有“应用参数”明确保存本区编辑值。保留应用运行时需要的初始化，不把“停止回写”误做成“停止初始化”。原值一旦被覆盖，不能从现存存储推算回来，需要允许重新填写。

### 先修：云端规则导入会丢掉仅存在本地的关键词和用户规则

位置：[SettingVM.cs:217](src/BiliLite.UWP/Modules/SettingVM.cs#L217) 和 [SettingVM.cs:237](src/BiliLite.UWP/Modules/SettingVM.cs#L237)。关键词和用户规则的 `Union` 没有物化，紧接着就清空本地集合；枚举合并结果时，本地一侧已空。服务器没有的本地规则因此丢失。正则分支已在清空前调用 `ToList`，形状不同。

修法：先把三个类别的合并结果各自形成快照，再修改可观察集合和持久化。失败不清空已有规则。按钮名称和帮助应明确为合并导入，不承诺上传。

### 一起修：添加视频规则没有实际上传

位置：[SettingVM.cs:273](src/BiliLite.UWP/Modules/SettingVM.cs#L273)。`AddDanmuFilterItem(word, type)` 没用传入的规则发起添加请求，而是再次读取云端规则。调用处却会显示“远程同步失败”，成功时也容易让人误以为已经上传。

修法：本轮整理按“添加到本地”定义按钮，去掉这条伪上传路径和错误提示；保留独立的“从账号导入”。若以后需要云端写入，再作为实际功能实现。不要只把成功文案改成“同步成功”。

### 一起修：鼠标开关在单窗口模式下不能关闭中键返回

位置：[NoTabMainPage.xaml.cs:52](src/BiliLite.UWP/NoTabMainPage.xaml.cs#L52)。条件相当于 `(开关 && 后退侧键) || 中键`，所以关掉设置仍会响应中键。标签页模式已经把两个按键放进同一组条件。

修法：单窗口分支也让开关包住两种按键。标签名用“鼠标返回”，帮助里说明返回与关闭页面的实际范围；不泛称所有侧键都受控。

### 一起修：直播关键词添加后清空了另一页的输入框

位置：[SettingPage.xaml.cs:1240](src/BiliLite.UWP/Pages/SettingPage.xaml.cs#L1240)。添加直播关键词后清空的是 `DanmuSettingTxtWord`，并非 `LiveDanmuSettingTxtWord`。直播输入保留旧词，还会擦掉视频页未提交的输入。

修法：只在添加成功后清空直播输入。顺手保留现有去重逻辑，不再重复写同一份列表。

### 一起修：手动添加正则先保存无效表达式

位置：[SettingPage.xaml.cs:1031](src/BiliLite.UWP/Pages/SettingPage.xaml.cs#L1031)。手动添加没有使用导入和加载时已有的正则检查，错误规则先入库，再在下次加载时被剔除。用户可能以为规则保存成功，之后又无故消失。

修法：添加前复用现有有效性检查；失败不保存、不清空输入。用户输入错误就在本行反馈，不只把问题写入日志。此处不扩展为整个弹幕引擎重构。

### 第一步：修保存和无效行为

修 API 路径错误与加载回写、规则合并丢失、伪上传提示、鼠标开关和输入框清错；删除失效的直播格式设置。先保证设置有真实含义，再移动界面。

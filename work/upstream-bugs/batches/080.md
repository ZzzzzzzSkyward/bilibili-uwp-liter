## [#1235 — Subtitle language selection does not carry across video parts](https://github.com/ywmoyue/biliuwp-lite/issues/1235)

The target `PlayerControl.SetPlayItem` clears active subtitles and reloads info for the selected part (`src/BiliLite.UWP/Controls/PlayerControl.xaml.cs:1019-1080`). A manual choice only updates the control's `CurrentSubtitleName` (`:1118-1129`); the next part's `GetPlayerInfo` rebuilds the menu and selects its first available language (`:1505-1588`). The target has no saved-language state, so it cannot reapply a non-default choice.

The sibling stores the selection as `aid|language` when the user chooses a subtitle (`/workspace/biliuwp-lite/src/BiliLite.UWP/Controls/PlayerControl.xaml.cs:1163`) and restores a matching language before default selection on the next part (`:1740-1754`, `:1777-1820`). This confirms the intended same-video part-switch behavior.

**Disposition:** validated logic bug. **Focused case:** choose a non-default subtitle on one part, switch to another part of the same video where that language exists, and assert it remains selected. No app code or tests were changed/run in this assessment.

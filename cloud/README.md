# cloud/ — 云端自主执行工作区

本目录是云端 agent 的唯一协作通道。读顺序：

1. 根 `AGENTS.md`（分支与入口指针）
2. `cloud/REPO.md`（本仓库参数：分支、安装/测试/构建命令）
3. `cloud/CONTRACT.md`（角色、轮次、文件通道、提交规则）
4. `docs/ROADMAP.md`（本轮候选大功能）
5. `cloud/memory/INDEX.md`（按需打开条目指向的记忆文件）

目录：

| 路径 | 用途 |
| --- | --- |
| `rounds/` | 每轮的需求、计划、审查、执行、验收文件（文件即通道） |
| `memory/` | 长期记忆与每轮摘要（只增不改） |
| `templates/` | 需求/审查/执行/验收模板 |

规则速记：主会话只调度不写代码；需求 → 审查 → 执行 → 实现审查，阶段内并行；记忆只进 `memory/`；完成后执行者提交并推送，主会话核对远端 SHA。

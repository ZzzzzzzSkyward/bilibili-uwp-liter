# 长期决策（append-only）

每条：日期 / 决策 / 理由 / 影响范围。

- 2026-11-24：采用 `cloud/CONTRACT.md` v1 作为云端统一执行规范。理由：主会话只调度、子代理分角色、文件即通道、记忆目录化。影响：所有云端轮次。

- 2026-11-25：维护优先修真实来源已证实的局部契约错误，保留账号解析 hold、播放器/SMTC/请求节奏的设备或测量前置；不以端点差异或模拟 UI 测试代替现网/设备证据。理由：既有已验收功能和凭证/来源/会话归属必须增量保护。影响：本轮维护计划及后续选题。
- 2026-11-25：评论发送恢复保留当前 HttpResults 的嵌入对象 salvage 兼容语义，不在对话框修复中全局改为严格 JSON 文档。用真实解码类提取与真实对话框测试说明结果，不能让更严格的 fake 掩盖生产策略。理由与边界见 `cloud/rounds/20261124-api-request-maintenance/comment-recovery/requirements.md` §4。
- 2026-11-25：维护周期是团队操作建议，不自动新增定期任务；用户明确请求的 20 分钟一次性唤醒已触发并继续原有所有权。理由：未指定循环频率，不推定无限重复。影响：自动化与维护节奏。
- 2026-11-25：CI 必须绑定真实 GitHub 事件/源码 SHA/结果；空运行历史不能证明禁用或通过，YAML 解析不能证明表达式可用。仅发布只读测试工作流与经审查的单次验证，不修改仓库/账号权限、发布线或设置来“变绿”。实际配置错误先修配置，实际权限/平台缺失明确阻塞。影响：QF2 及后续 CI 维护。

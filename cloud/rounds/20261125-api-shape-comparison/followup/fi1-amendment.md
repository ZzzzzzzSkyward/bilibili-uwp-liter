## Ownership and readiness contract

`Loading` represents the active result owner; `ConditionsLoading` represents the active conditions owner. Neither request is owned in a new VM. Initial conditions still begin immediately through the existing page navigation; result Loading must not cover that wait. A first LoadConditions call must be allowed. Ownership guards are inside SeasonIndexVM and protect every public method/command, including direct callers; a XAML button/selection guard alone is insufficient.

A usable Parameter means **Parameter is nonnull**, not a new enum/range/format policy. Usable Conditions means a nonnull, nonempty collection whose entries each have a nonempty field name, a nonnull selected `current`, and a nonnull selected `current.keyword`. An empty keyword is still a valid empty value; preserve its existing URI encoding. Unknown nonempty field names and existing order/filter values are not allowlisted, trimmed, normalized or changed. This is the minimum structural readiness for the existing named-filter builder, not a new parser/catalog/selection fallback. Preserve the current data.filter/order reads, casts, default selection and Conditions publication. If decoded metadata has no selected match, the result entry quietly declines ownership; Refresh can reload metadata once, rather than issuing a malformed/premature result or selecting a new fallback.

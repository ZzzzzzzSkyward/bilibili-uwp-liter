Off-thread serialization/Save, handled async-void failures, and a non-poisoned successor after a failed write are explicit acceptance conditions, not optional implementation details.

**Registry and grants:** The static service is callable from multiple separately created DownloadPage tabs; a disabled import button protects only one page instance. The required single async gate owns the entire registry read/modify/provisional-grant/staged-commit/retirement transaction and its fixed temp file. All exit paths release in finally, and no gate-taking private read may be reentered under the same semaphore. These requirements address both genuine interleavings while retaining staged-write failure recovery and typed stage behavior.
